## 后续

本版完成“视频 → 可见角度 → 局部检查 → 时间点 → 人工复核/导出”的链路。推胸自动局部候选目前只有固定机位下的躯干相对参考变化；其他通用技术要点有来源和复核入口，尚无自动检测实现。数字门槛是研究设定，不冒充来源标准。

优先完善主体锁定、局部可见性与拍摄变化检测，再为上臂轨迹、肩部变化、回程控制建立教练标注与独立验证，分别统计局部误提醒、漏提醒和延迟。推胸相机训练接入、真实耳机播放、更多解码器/旋转视频及低端手机资源测试仍待完成。不做整次动作“标准/错误”二分类。
