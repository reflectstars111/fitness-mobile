# 实时动作提醒 0.2 契约

规则版本 `coach-research-1`，实现位于 `core/.../LiveCoach.java`，调度位于 `FeedbackGate.java`。新增规则为本项目独立实现，未复制第三方教练程序。阈值是待真人与教练校准的工程默认值，不代表通用合格标准。

## 使用流程与适用范围

选择深蹲或站姿弯举 → 固定手机在所选身体侧面、单人全身入镜 → 测试耳机 → 开始一组 → 自然伸展并站稳，记录准备姿势 → 训练。可以关闭动作提醒、关闭语音或关闭语音中的角度。手机使用离线中文 TTS；缺少离线声音时显示文字。

只使用二维可见关节及过去观测。没有实现膝内扣、脊柱弯曲、负重、疼痛或动作安全性的判断。没有提醒不等于动作达标。弯举提醒针对相对准备姿势的上臂变化和躯干变化；深蹲幅度目标必须由用户主动开启，默认关闭。

## 观测与准备姿势

- 相机时间戳使用 Android uptime 单调时钟。到达时超过 350 ms 的画面或未来时间戳不得用于动作评价；相邻观测超过 350 ms、重复/乱序、有效追踪 epoch 改变会重置准备姿势。
- 看不清、多人、机位不适配时清除动作证据。每种持续可见性问题在连续观测达到 1200 ms 后形成摆机位候选。完全断流超过 600 ms 时停止旧语音、清除画面和评价，仅显示断流状态；本版尚无独立断流语音告警。
- 初始屈曲不大于 25°、躯干相对竖直不超过 20°、弯举上臂相对躯干不超过 30°，稳定至少 1200 ms 且至少 8 帧。相对首帧角度变化不得超过 6°；变化后重新取样。
- 准备姿势保存该段均值。上臂相对躯干角度为 `wrap(upper_arm_tilt_deg + trunk_lean_deg)`，变化量为相对于准备均值的最短圆周差绝对值。正负方向由几何坐标定义，不直接套用左右屏幕方向；已测试镜像不变性。
- 暂停、遮挡和换机位后需要重新记录。准备姿势只是本组比较参考，不能证明起始姿势正确。

## 当前提醒

| 规则 | 持续证据 | 行为 |
| --- | --- | --- |
| `curl:trunk` | 弯举屈曲 >25°，躯干偏离准备姿势 >12°，持续 700 ms | 提醒站稳、减少身体摆动；优先于上臂提示 |
| `curl:arm` | 弯举屈曲 >25°，上臂相对躯干偏离准备姿势 >15°，持续 700 ms | 提醒肘部回到身体两侧附近、保持上臂稳定 |
| `squat:goal_reached` | 主动开启目标，当前屈膝达到目标、计数阶段非 READY，持续 300 ms | 提示已到自设幅度，保持控制、按计划返回 |
| `squat:target` | 已观察到返回站立，周期 ≥600 ms，最大屈膝 ≥35° 且比自设目标少 >10° | 提示本次最大屈膝和目标；建议下次在舒适范围内调整 |

深蹲目标范围 40–120°，步进 5°，伸直为屈曲 0°；界面同时区分关节夹角与屈曲角，二者相加为 180°。语音角度四舍五入到约 5°，并使用“约”字，不冒充仪器精度。未达到计数阈值的浅蹲也能在已观察到返回后形成幅度提示，不从未来帧回填峰值。下一次动作开始或证据丢失撤销上一次幅度提示。

## 调度、语音与记录

优先级依次为机位/可见性 100、准备 90、躯干 80、上臂 70、深蹲目标 60、报数 10。每次只选当前最高优先级候选；持续问题已播报时仍抑制低优先级报数。同一证据段只投递一次；新的同规则提醒至少间隔 10 秒，报数至少 2 秒。一般提醒全局间隔 4.5 秒，报数后 1.5 秒、动作提醒后报数 2 秒；准备提示之后或更高优先级可立即投递，但语音仍受播放状态限制。

不维护待播队列。每个候选有证据开始/结束时间和结束后 1500 ms 的播放开始期限。开始播放前再次检查过期；高优先级到来、证据消失、暂停或音频焦点丢失时取消旧语音。音频忙或焦点请求失败时不消费候选，只在它仍是当前有效候选时尝试。持续观测刷新证据末尾，但不改变证据段 ID。

本地导出 schema 2 保留旧计数事件，增加 `feedback`、`standingReferences` 和自设目标。提醒记录包括规则版本、证据时间段、测量值、参考值、准备姿势引用时间、文本、优先级、过期时间与投递状态。`spokenAtUptimeMs` 来自 TTS 的 onStart 回调；不是耳机声波到达时间。文字模式不填写该时间。取消、错误和完成状态分别记录。旧 schema 1 历史仍可读取。默认不保存原始视频或逐帧图像。

## 依据与待验证项

[NASM 的深蹲生物力学说明](https://www.nasm.org/resource-center/blog/training/biomechanics-of-the-squat)讨论了深蹲深度受活动度、身体结构等因素影响，因此本版采用用户选择的目标，不指定统一“正确深度”。文献说明不验证本项目二维测量或上述数值阈值。后续需要教练标注、授权真人样本、独立留出集，以及误提醒率、漏提醒率和提醒延迟评估。
