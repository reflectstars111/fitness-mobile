# 通用器械推胸技术要点与自动分析边界

整理日期：2026-09-07。适用于一般坐姿器械推胸，不要求使用者填写品牌、型号或铭牌。动作变式、可见性和个体活动范围仍需区分；通用训练指导不等于已经验证的视觉分类器。

## 来源与共同要点

NASM 的 [Chest Press Machine](https://www.nasm.org/resource-center/exercise-library/chest-press-machine) 提供通用动作教学；[Life Fitness Optima 使用手册第 20 页](https://www.lifefitness.com.au/wp-content/uploads/2015/02/Optima_user_manual_for_all_strength_2_585_1371787541.pdf#page=21)作为器械制造商的一手说明，用于交叉核对坐姿推胸技术。后者是具体器械示例，不要求用户使用该型号，也不把它独有的调节档位作为通用规则。

| 通用检查项 | 技术要点 | 本项目当前能做什么 |
| --- | --- | --- |
| 起始高度 | 平推起始把手约在胸部中段；勿把肩推、上斜推举混用为同一动作 | 展示画面供复核；没有把手检测和胸部高度标定 |
| 身体支撑 | 背部由靠背支撑、双脚稳定支撑、肩部保持稳定 | 固定机位下检查相对准备姿势的持续躯干变化，形成局部提醒候选；不能证明背部或脚底接触、肩胛位置 |
| 上臂和肘部 | 肘部不应任意外张或内收，结合握法与器械轨迹；NASM 用约 45° 描述上臂相对躯干的位置，厂商示例要求起始肘略低于肩 | 不能将该 45° 与斜拍肘关节夹角直接比较 |
| 动作控制 | 推出和回程均保持控制，避免突然甩动或失控回落 | 可逐时刻检查轨迹；没有经验证的“过快”角速度阈值 |
| 推出终点 | 受控伸展，不强行锁肘；活动范围结合个人条件与轨迹 | 展示可见侧二维肘夹角；不能据此确诊锁肘、过伸 |
| 回程 | 在可控制范围内回到起点，配重式器械避免失控落下 | 配重堆、握把起点和个人活动范围尚未测量 |

上述表格是对两份来源的归纳。其中身体支撑、约 45° 与避免锁肘来自 NASM；起始肘略低于肩、配重控制由厂商手册补充。两份资料都强调控制动作，但并未给出适用于所有人的肘角合格区间或回程秒数。

## 数值如何使用

“上臂相对躯干约 45°”“肘夹角”和“肘屈曲角”是不同量。当前 `elbow_flexion_deg` 为二维肘屈曲量，界面显示的肘夹角为 `180 - elbow_flexion_deg`。宽松衣服、遮挡、透视和关节定位误差都会影响估计。

因此当前不采用“肘必须 90°”“推出必须 170°”或“躯干必须竖直”等硬编码标准，不把 NASM 的约 45° 直接变成任意视角的误差阈值。靠背自然倾斜不等于站姿弯举中的身体借力，不能迁用弯举躯干门槛判断推胸。

后续泛化应围绕通用动作特征建立：可靠主体与视角 → 可见上肢轨迹 → 个人可控幅度参考 → 推出/返回阶段 → 持续偏离的证据。实验候选需经过独立教练标注验证再升级为正式提示；不依赖品牌分类，也不靠记住一段视频调参。

## 已接入应用

`protocols/machine-chest-press.v1.json` 是版本化规则参考，随 APK 打包。器械推胸模式逐帧输出六项 `technicalChecks`，报告保留来源。身体支撑项接入 `ChestPressCoach`，其余项目先保留为人工复核。界面支持按项目关联时间点人工备注，标记为 `user_unverified`，不把使用者备注当作认证教练真值。

局部躯干规则：固定机位、单主体、所选侧肩/肘/腕/髋可见；稳定姿势至少 1200 ms、至少 8 帧且与首帧角度差不超过 4°后取均值。之后观察到肘屈曲变化超过 8°，在最近 1500 ms 的运动期间，躯干相对参考变化超过 12°并持续 700 ms，输出 `chest:trunk_change`。观测间隔超过 350 ms、重复/乱序、身份变化、局部遮挡均重置。允许靠背倾斜作为参考，不采用竖直躯干目标。腿部看不全不单独阻断可见上肢的这一检查。

上述数字是明确标记的工程试验门槛，**并非 NASM 或制造商规定的标准值**。提示为“躯干相对本组准备姿势变化约 X 度，请保持身体稳定，检查背部支撑”，不推断重量过大或背部必然离开靠背。证据消失即撤销，调度去重/过期沿用反馈契约。本版仅在回放中输出该推胸局部提醒，相机训练目前仍为深蹲和站姿弯举。

结果按部位输出，不生成整次动作的合格/不合格判决。局部发现、暂无持续候选、局部看不清和待人工复核应分别展示。
